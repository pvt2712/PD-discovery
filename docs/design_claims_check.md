## Notes that change the design

1. **Fix citations.** J-PCMCI+ is arXiv 2306.12896; AVICI is 2205.12934. Cite BOSS-FCI and FCIT to Ramsey, Andrews, Spirtes (arXiv 2510.04263), and drop "faster than GFCI".
2. **Rephrase Pal 2025:** "argued FCI does not scale when p ≫ n; proposed a lasso-screened FCI (n = 199)".
3. **PPMI numbers.** Drop the 1,693 breakdown. Cite NCT04477785 for the target and Marek 2018 for PPMI 1.0.
4. **DECI cannot carry the missing-data argument.** The maintained package needs complete or imputed rows and assumes no latent confounders.
5. **Environments.** causica needs Python 3.10, AVICI and SDCD ≤ 3.11, and py-tetrad ≥ 3.12 plus JDK 21; BayesDAG is Python 3.8 research code and DCDI has no package, so use separate uv environments. Pin Tetrad 7.6.10, because the development branch renamed `BossFci` to `Bfci`.
6. **Foundation models.** Arrow and CDFM run and are openly licensed, but both were trained on ≤ 100 i.i.d. variables and neither has been validated on clinical panels; use them as screens only.
